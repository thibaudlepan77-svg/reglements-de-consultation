# Ce que disent vraiment 145 règlements de consultation

Six chiffres mesurés sur 145 règlements de consultation de marchés publics
français de travaux, téléchargés anonymement sur les profils acheteurs entre
le 25 et le 29 août 2026.

La page publie la méthode, le comptage à trois compartiments (oui, non,
muet), les limites de l'échantillon, et les quatre fois où les chiffres
publiés étaient faux avant audit.

Lecture en ligne : https://thibaudlepan77-svg.github.io/reglements-de-consultation/
